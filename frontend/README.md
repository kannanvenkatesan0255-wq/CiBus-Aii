# CIBUS-AI Web Frontend

**Project:** CIBUS-AI – AI-Based Food Surplus Prediction and Redistribution Network  
**Tagline:** *"Predict. Connect. Nourish."*  
**Module:** React / Vite Frontend User Interface  
**Version:** `1.0.0`

---

## 1. Frontend Purpose
The CIBUS-AI web frontend provides a responsive, glassmorphism-styled dashboard for dining operators (commercial restaurants, banquet halls, hotel kitchens, college cafeterias) to input pre-service operational metrics and receive real-time surplus meal predictions generated by the trained Random Forest Machine Learning engine via the FastAPI backend.

---

## 2. Technology Stack
- **UI Framework:** [React](https://react.dev/) (v18.3+)
- **Build Tool & Dev Server:** [Vite](https://vitejs.dev/) (v5.4+)
- **Styling:** Custom Vanilla CSS Design System with dark glassmorphism, responsive grid layouts, and custom typography (`Outfit` and `Plus Jakarta Sans`).
- **HTTP Client:** Native Fetch API with structured error parsing and timeout resilience.
- **Testing:** Node-based automated assertion and component audit test runner (`npm test`).

## 4. Environment Configuration
Create a `.env` file (or rely on the default Vite proxy):
```bash
# Template: .env.example
VITE_API_BASE_URL=http://127.0.0.1:8000
```
*Note: `.env` is ignored by Git to ensure no environment secrets are committed.*

## 5. Running Locally

### Step 1: Install Node Dependencies
```bash
cd frontend
npm install
```

### Step 2: Start Development Server
```bash
npm run dev
```
The application will launch at `http://localhost:5173`.

### Step 3: Run Frontend Tests
```bash
npm test
```

### Step 4: Build for Production
```bash
npm run build
```

## 6. Prediction Workflow & Data Flow
1. User enters 9 operational parameters (e.g., `Day`, `Weather`, `Customers_Forecast`, `Meals_Prepared`, `Event_Type`, etc.).
2. `PredictionForm.jsx` validates input boundaries and ensures `Meals_Sold` is omitted.
3. `predictionService.js` issues `POST /api/predict` to the FastAPI backend.
4. The backend runs the pre-fitted `ColumnTransformer` and executes `food_surplus_model.pkl`.
5. `ResultCard.jsx` prominently displays the forecasted surplus meals along with tailored logistics guidance.
